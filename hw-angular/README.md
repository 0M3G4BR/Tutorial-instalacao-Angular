# SPA com Angular

## Pré-requisitos
- Node.js vX.X.X
- npm X.X.X

## Criação do projeto
npx @angular/cli@latest new spa-angular --skip-git

## Como rodar
cd spa-angular
npm install
npm start
Acessar http://localhost:4200

## Estrutura dos arquivos gerados
(1 parágrafo: package.json lista dependências e scripts; angular.json
configura o build; src/index.html é a única página HTML; src/main.ts é o
ponto de entrada que inicializa a aplicação; src/app/app.ts é o componente
principal, com a lógica e o template do Hello World e do contador.)
